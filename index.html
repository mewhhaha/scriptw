scriptw

Formerly Porffor.

Scriptw is an experimental JavaScript-to-WebAssembly compiler written in Rust. Compile JavaScript and its builtins to Wasm, run it through Wasmtime, or embed it in a Rust application. WebAssembly is the sole output target.

Architecture

JavaScript source → parsing and early errors → spec-shaped IR → lowering IR → real Wasm code generation. Emitted programs are compiled user code, not an interpreter or VM bundled into Wasm.

Build and run

git clone https://github.com/mewhhaha/scriptw.git
cd scriptw
./scripts/dev.sh build
./target/debug/scriptw run program.js

Read the README and current conformance status, or browse the source.
